GitOps Automated Workflow

From code push to cluster synchronization without manual intervention.

1. Code & Manifest

Update HTML or Kubernetes manifests (`deployment.yaml`) in local workspace.

2. Version Control

Commit and push updates to GitHub `portfolio-01` main branch.

3. Argo CD Sync

Argo CD controller detects state drift and triggers automated sync.

4. K8s Cluster

Docker Desktop K8s runs 4 pod replicas with self-healing active.

Self-Healing & Automation

Kubernetes maintains the desired state automatically. If any pod is terminated or fails, a fresh container replica is instantly provisioned.

$ kubectl delete pod portfolio-deployment-xxx

-> New replica spawned automatically (Desired: 4)
